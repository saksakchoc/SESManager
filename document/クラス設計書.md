# クラス設計書

## 1\. 前提

本ツールは、SES営業・事務スタッフ向けのエンジニア・案件管理CLIツールである。

初期版では、以下を前提とする。

- Java標準ライブラリで実装する  
- フレームワークは使用しない  
- データ保存はメモリ上のみ  
- DB連携は行わない  
- CLI入出力部分とロジック部分は分離する  
- JUnitテスト対象はロジック層のみとする  
- 編集機能は初期版では作らない  
- ただし、将来の編集機能追加を考慮し、主要データクラスは record ではなく通常の class とする

## 2\. 設計方針

### 2.1 データクラスの方針

初期版で扱う主要なデータクラスは以下の3つとする。

- Engineer  
- Project  
- Participation

### 2.2 案件情報と募集情報の扱い

初期版では、案件情報と募集情報は分けない。

理由：

- 初期実装の難度を上げすぎないため  
- 要件定義書上も、案件登録項目として一体で扱っているため  
- 同一顧客・同一案件名でも、募集条件が異なる場合は別案件として登録する運用で代替できるため

将来拡張として、案件情報と募集情報の分離を検討する。

### 2.3 recordを使わない理由

Engineer / Project / Participation は、将来的に編集機能を追加する可能性があるため、record ではなく通常の class とする。

初期版では setter を最小限にするが、将来的な拡張余地は残す。

### 2.4 参画期間の扱い

初期版では、契約途中での参画開始・離任は扱わない。

そのため、以下の運用とする。

- 参画開始日 \= 案件開始日  
- 参画終了日 \= 案件終了日

ただし、将来的にエンジニアごとに参画期間が異なるケースへ拡張できるよう、Participation 側にも開始日・終了日を保持する。

## 3\. データクラス一覧

| クラス名 | 種類 | 役割 |
| :---- | :---- | :---- |

| Participation | データクラス | エンジニアと案件の参画関係を表す |

## 4\. Engineer クラス

### 4.1 役割

エンジニア1名分の基本情報を保持する。

参画情報は直接持たない。 参画情報は Participation クラスで管理する。

### 4.2 フィールド

| 項目名 | 型 | 説明 |
| :---- | :---- | :---- |
| id | int | エンジニアID |
| name | String | 氏名 |
| price | int | 単価目安 |
| skills | ArrayList | スキルセット |

### 4.3 メソッド候補

| メソッド名 | 戻り値 | 説明 |
| :---- | :---- | :---- |
| getId() | int | エンジニアIDを返す |
| getName() | String | 氏名を返す |
| getPrice() | int | 単価目安を返す |
| getSkills() | List | スキルセットを変更不可のコピーとして返す |

### 4.4 コンストラクタ・引数のチェック

- エンジニアid, 氏名, 単価目安,  スキルセット(任意)を受け取ってメンバにセットする  
- 氏名は以下の通りチェック  
  - null: NullPointerException  
  - 空文字（空文字のみ）: IllegalArgumentException  
- 単価目安は以下の通りチェック  
  - 1以上の整数でない: IllegalArgumentException

### 4.5 設計メモ

- setter は初期版では作らない  
- 編集機能は初期版では作らない  
- getSkills() では内部の ArrayList を直接返さない  
- getSkills() は List.copyOf(skills) 相当で返す  
- スキル名は、大文字小文字違いや空白有無などの表記揺れは許さず、異なる文字列であれば別スキルとして扱う。

---

## 5\. Project クラス

### 5.1 役割

案件1件分の情報を保持する。

初期版では、案件情報と募集情報を分けず、Project にまとめて持たせる。

### 5.2 フィールド

| 項目名 | 型 | 説明 |
| :---- | :---- | :---- |
| id | int | 案件ID |
| name | String | 案件名 |
| startDate | LocalDate | 開始日 |
| endDate | LocalDate | 終了日 |
| skills | ArrayList | 必要スキルセット |
| minPrice | int | 単価下限 |
| maxPrice | int | 単価上限 |
| status | RecruitingStatus(enum) | 募集中区分 |

### 5.3 メソッド候補

| メソッド名 | 戻り値 | 説明 |
| :---- | :---- | :---- |
| getId() | int | 案件IDを返す |
| getName() | String | 案件名を返す |
| getStartDate() | LocalDate | 開始日を返す |
| getEndDate() | LocalDate | 終了日を返す |
| getSkills() | List | 必要スキルセットを変更不可のコピーとして返す |
| getMinPrice() | int | 単価下限を返す |
| getMaxPrice() | int | 単価上限を返す |
| isRecruiting() | boolean | 募集中かどうかを返す |
| setRecruitingStatus(RecruitingStatus status) | void | 募集中区分を変更する |

### 5.4 募集中区分

募集中区分は enum とする。

想定値：

| 値 | 意味 |
| :---- | :---- |
| RECRUITING | 募集中 |
| CLOSED | 募集終了 |

### 5.5 設計メモ

- 募集中区分は Project に持たせる  
- Participation の有無だけでは募集中かどうかを判断しない  
- 理由は、自社エンジニア以外が参画している案件や、追加募集している案件があり得るため

## 6\. Participation クラス

### 6.1 役割

エンジニアと案件の参画関係を表す。

「どのエンジニアが、どの案件に、いつからいつまで、いくらで参画するか」を保持する。

### 6.2 フィールド

| 項目名 | 型 | 説明 |
| :---- | :---- | :---- |
| id | int | 参画情報ID |
| engineer | Engineer | 参画するエンジニア |
| project | Project | 参画先の案件 |
| startDate | LocalDate | 参画開始日 |
| endDate | LocalDate | 参画終了日 |
| contractPrice | int | 契約単価 |

### 6.3 メソッド

| メソッド名 | 戻り値 | 説明 |
| :---- | :---- | :---- |
| getId() | int | 参画情報IDを返す |
| getEngineer() | Engineer | エンジニアを返す |
| getProject() | Project | 案件を返す |
| getStartDate() | LocalDate | 参画開始日を返す |
| getEndDate() | LocalDate | 参画終了日を返す |
| getContractPrice() | int | 契約単価を返す |

### 6.4 設計メモ

- ステータスは持たない  
- 参画中 / 参画前 / 参画終了は、開始日・終了日と基準日から判定する  
- ステータスを持つと、日付との二重管理になるため  
- 初期版では、参画開始日・参画終了日は案件開始日・案件終了日と同じ値を設定する

## 10\. AssignService クラス

### 10.1 役割

エンジニアと案件のアサイン可否判定、参画情報の検索、およびアサイン処理を行う。

### 10.2 フィールド

| 項目名 | 型 | 説明 |
| :---- | :---- | :---- |
| participationStore | ParticipationStore | 案件参画状態のリスト |

### 10.3 メソッド

| メソッド名 | 戻り値 | 説明                                                                                                                                                                                                                                                |
| :---- | :---- |:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| canAssign(Engineer, Project) | boolean | 対象エンジニアが対象プロジェクトにアサイン可能であればtrueを返す                                                                                                                                                                                                                |
| getEngineerParticipation(Engineer) | ArrayList | 対象エンジニアが参画中(予定/済)の案件に関するParticipationインスタンス配列を返す                                                                                                                                                                                                  |
| isAvailableByDay(Engineer, LocalDate) | boolean | 対象日付に対象エンジニアが参画中の案件がない場合trueを返す                                                                                                                                                                                                                   |
| isAvailableByPeriod(Engineer, LocalDate startDate, LocalDate endDate) | boolean | 対象期間に対象エンジニアが参画中の案件がない場合trueを返す                                                                                                                                                                                                                   |
| isAvailableByPrice(Engineer, int 最低単価, int 最高単価) | boolean | エンジニアの単価目安が、引数の最低単価～最高単価に含まれている場合trueを返す                                                                                                                                                                                                          |
| isAvailableBySkills(Engineer, Listスキル一覧) | boolean | エンジニアが、引数のスキル一覧をすべて有している場合trueを返す                                                                                                                                                                                                                 |
| executeAssign(Engineer, Project) | boolean | 対象エンジニアを対象案件に参画させる（参画関係オブジェクトを作成し、participationStoreに追加する） `canAssign()` → `ParticipationStore.createParticipation()` → `Project.setRecruitingStatus()` の順に呼び出す。成功したらtrue, canAssignの結果、案件参画条件を満たさなければ登録処理をせずfalseを返して終了 ※登録処理失敗時はfalseではなく例外を投げる |

#### canAssignメソッド詳細

すべての条件を満たす場合trueを返す

- Projectのステータスが「募集中」である  
- 案件の募集期間中に対象エンジニアが案件に参画していない  
- 案件の必要スキルをエンジニアがすべて保有している  
- エンジニアの目安単価が、案件の単価上下限以内である

#### ExecuteAssignメソッド詳細

- 契約単価は、アサイン時点のエンジニア目安単価とする  
- `createParticipation()` で例外が発生した場合は保存・ステータス変更を行わない
