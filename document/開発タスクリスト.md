# SESManager 開発タスクリスト

更新日：2026-11-15（日本時間）

## このファイルの使い方

- 日々の作業は「次に進めること」から1件ずつ進める。実装は本人が行い、アシスタントは相談・レビュー・依頼された記録整理を支援する。
- このタスクリストのPRをマージ後、Gitの本ファイルを通常の進捗更新先とする。旧Page・旧Sheetは履歴とし、二重更新しない。自動同期は行わない。
- 変更した機能のPRで、関係するタスクの状態・確認結果・参照SHAも更新する。チェックだけでUC全体を完了扱いにしない。
- 「実装あり」「本人の動作確認」「テスト実行結果」「マージ済み」を区別する。未pushの作業を未実装と決めつけない。
- 完了条件を満たした作業だけチェックする。分からない点は該当タスクに残し、他の作業を止めない。
- Java標準ライブラリ・JUnit 5・Maven、フレームワークなし、メモリ保存、Windows CLIを前提とする。CLIは手動確認、ロジック層はJUnitで確認する。

## 今回までに確認できたこと

### developにある実装

- EngineerStore・ProjectStoreの全件取得は `List.copyOf` で返す。
- 両Storeに0件・複数件・取得リストへの追加不可・取得後にStoreへ登録しても取得済み件数は不変、のテストコードがある。
- メインメニュー、NavigationResultによるコントローラ、エンジニア登録・詳細表示がある。
- AssignServiceの期間・単価・スキル・募集状態による判定、参画情報取得、executeAssignがある。executeAssign成功/判定NGのテストコードもある。
- ここでの「ある」はソース確認であり、最新テスト実行済みを意味しない。

### PR #3にある実装（未マージ）

- 検索方法の選択、全件表示、ID検索、一覧の番号選択と詳細への接続。
- 一覧は `List<Engineer>` を引数で受け取り、詳細のBで同じリストを再表示する。登録後の詳細からBの場合はコントローラが全件を渡す。
- 一覧0件時はメッセージを表示して検索へ戻る。
- 詳細・一覧・検索で戻り値を受け渡し、Mでメニューまで戻る。
- 詳細にエンジニアID・参画案件IDを表示。
- 不存在IDはnull判定を行い、メッセージを出してID再入力へ戻す（`c53d247`）。
- 条件検索は仮処理、ID検索中のM/BとID指定から詳細への直接遷移は未対応。UC-02全体は未完了。
